# Fork changes (Creator 5 Pro personal build)

Base: upstream OrcaSlicer tag `v2.4.2`. Integration branch `ff-main`; one feature per `ff/<name>` branch.
To move to a new upstream tag: `git fetch upstream --tags && git rebase --onto <new-tag> v2.4.2 ff-main`.

| Change | Files | Why |
|---|---|---|
| Windows x64 CI build | `.github/workflows/ff_build_windows.yml` (new) | Installer without a local compiler; separate file so upstream workflows stay untouched. |
| Keep all 3MF settings (pref `ff_keep_3mf_settings`, default on; Preferences > "Keep all settings saved in 3MF files") | `Preset.cpp/.hpp` (`load_external_preset` `rebase_on_system`), `PresetBundle.cpp/.hpp`, `Plater.cpp`, `AppConfig.cpp`, `Preferences.cpp` | Stock Orca resets every key not in `different_settings_to_system` to the same-named installed system preset. Flash Studio's presets share names with Orca's Flashforge presets but not values, so its projects lost tower, filament and toolchange settings in the GUI. Flash Studio files carry no distinguishing metadata, hence a preference rather than detection. |
| Side-by-side identity `OrcaSlicer-C5P` | `version.inc` (`FF_APP_ID`), `libslic3r_version.h.in`, `CMakeLists.txt` (CPack name, file name, install dir, uninstall registry key, Start menu name), `GUI_App.cpp` (data dir, ProgID `Orca.Slicer.C5P.1`, no `orcaslicer://` registration, no upstream update prompt) | Never touches stock Orca's install, `%APPDATA%\OrcaSlicer` settings or links. `SLIC3R_APP_KEY` is unchanged on purpose: it also names translation catalogs, icons and 3MF metadata. |
| Re-prime into infill without prime tower (print setting `prime_into_infill_without_tower`, default off; Multimaterial > Flush options) | `PrintConfig.cpp/.hpp`, `Preset.cpp`, `Print.cpp` (planned in step psWipeTower when there is no tower, shortfall warning), `GCode/ToolOrdering.cpp/.hpp` (`reprime_into_infill_active`, `WipingExtrusions::mark_reprime_extrusions`, `collect_extruders` keeps each region's own tool), `Tab.cpp`, `ConfigManipulation.cpp` | Tool changer with the tower off: stock does no re-prime at all and silently ignores the flush options. Each change now re-primes `prime_volume` into same-material sparse infill (objects with flush into infill), then into flush-into-this-object purge objects; an island's own infill may go before its walls; the rest is skipped and warned. Off = stock output. |
